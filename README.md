# HP1 Police Mod — الموقع + لوحة التحكم + بوت ديسكورد

دخول لوحة التحكم = بحساب ديسكورد + **رول تحدده أنت** (بدون كلمة سر).


## ⚡ إعداد مبسّط (التوكن فقط في .env)
`.env` يحتاج سطر واحد فقط:

    DISCORD_BOT_TOKEN=التوكن

الباقي يُحسب أو يتعدل من الموقع:
- Client ID ← يُؤخذ من التوكن · مفتاح الجلسة والمفتاح الداخلي ← يُشتقان من التوكن
- أيدي السيرفر ← يُكتشف تلقائياً (لو البوت في سيرفر واحد) أو يُحدد من اللوحة
- رابط الرجوع ← يُحسب من عنوان الموقع (لازم تضيفه في Discord Developer Portal ← OAuth2 ← Redirects)
- **Client Secret / رول الناجح / رولات الإدارة** ← من اللوحة ← 👑 إعدادات خاصة
- أول مرة (قبل ما تقدر تسجل دخول): افتح `/setup` في موقعك، اكتب التوكن كتأكيد وعبّئ الـ Client Secret.

⚠️ على Render المجاني الملفات تنمسح عند كل إعادة تشغيل/نشر. لحفظ التعديلات من اللوحة بشكل دائم أضف Disk في Render واربطه على `/var/data` (يُكتشف تلقائياً)، أو حدد `DATA_DIR`.

## الهيكل
- `public/`   الموقع فقط (الوحيد المفتوح للعامة)
- `private/`  لوحة التحكم + البيانات (لا تُخدم إلا لصاحب الرول)
- `server.js` السيرفر (بدون مكتبات)
- `bot.js`    بوت discord.js (/نتيجتي و /فك-الانتظار)
- `.env`      الإعدادات — عبّئ الحقول الفاضية فقط

## الإعداد (https://discord.com/developers/applications)
1. New Application ← انسخ **Application ID** (→ DISCORD_CLIENT_ID).
2. OAuth2 ← انسخ **Client Secret**، وأضف Redirect: `http://localhost:3000/auth/callback`
3. Bot ← Reset Token (→ DISCORD_BOT_TOKEN). لا تفعّل أي Privileged Intent.
4. OAuth2 ← URL Generator: scopes `bot` + `applications.commands`، صلاحية **Manage Roles** ← أدخل البوت لسيرفرك.
5. فعّل Developer Mode في ديسكورد، وانسخ (كليك يمين ← Copy ID):
   أيدي السيرفر (DISCORD_GUILD_ID) وأيدي رول الإدارة (DISCORD_ADMIN_ROLE_ID).
6. اجعل رتبة البوت فوق رتبة الناجحين (لو استخدمت DISCORD_PASS_ROLE_ID).

## التشغيل
    node server.js              ← الموقع http://localhost:3000   اللوحة /admin
    npm install && node bot.js  ← البوت (الوحيد اللي يحتاج مكتبة)

## على الاستضافة
- `.env`: `NODE_ENV=production` و`TRUST_PROXY=1` و`DISCORD_REDIRECT_URI` بـ https (وأضفه في OAuth2 Redirects).
- شغّله خلف HTTPS، ولا تشارك `.env`، وامنع `/internal/` من الخارج في Nginx.
- سحب الرول من شخص يسري خلال 4 ساعات كحد أقصى (مدة الجلسة).

## لوحة التحكم — الخانات والصلاحيات
- زر «🛠️ لوحة التحكم» يظهر في الموقع تلقائياً لمن سجّل دخول بديسكورد ويملك رول الإدارة، ويفتح اللوحة بدون تسجيل ثاني.
- خانة **إعدادات الموقع**: تعديل القوانين وتواصل معنا (اسم + صورة + رابط).
- خانة **🎨 تصميم الموقع**: تغيير الشعار والخلفية (ووضوحها) وألوان الموقع مع معاينة مباشرة. تُحفظ في `site.json` وتتطبق على الموقع بدون تعديل كود.
- المالك فقط يشوف أسفل كل خانة بلوك «صلاحيات هذه الخانة» لتحديد الرولات المسموح لها؛ من ما معه الرول يطلع له 🔒.
- البيانات: `private/data/site.json` و`perms.json` والصور في `private/data/uploads/` (على Render المجاني تنمسح عند إعادة التشغيل، استخدم Disk دائم).

## إرسال النتائج بالبوت
- بدل الويب هوك: البوت يرسل نتيجة كل متقدم لروم الإدارة كإيمبد (🟢 أخضر للناجح، 🔴 أحمر للراسب) مع معلوماته وتفاصيل إجاباته.
- الإعداد: ضع أيدي الروم في `.env` ← `DISCORD_RESULTS_CHANNEL_ID` (كليك يمين على الروم ← Copy Channel ID).
- لازم البوت يشوف الروم وعنده صلاحيات: View Channel + Send Messages + Embed Links.
